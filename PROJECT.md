# JUMANJI · Тайна затерянного мира

Кооперативная браузерная игра для команды до 4 игроков. Каждый играет со своего устройства в одной комнате. Проект использует Phaser, Vite и Supabase, публикация идёт на GitHub Pages.

Послания и подсказки всех локаций оформлены в общем стиле пергамента с зелёными и золотыми акцентами.

## Рабочая игра и тесты онлайн

| Ссылка | Что открывается после входа в комнату |
| --- | --- |
| [Рабочая игра](https://katrinanov.github.io/quest-lostworld/) | Обычное прохождение с первой локации |
| [Тест храма](https://katrinanov.github.io/quest-lostworld/?test=temple) | Сразу «Храм испытаний» |
| [Тест лабиринта](https://katrinanov.github.io/quest-lostworld/?test=maze) | Сразу «Лабиринт забвения» |

Для проверки команды откройте одну и ту же ссылку на всех устройствах. На первом создайте комнату, на остальных подключитесь по её коду. Используйте новую комнату для чистого прохождения. Онлайн-тесты используют настоящий Supabase и опубликованную сборку. Статус публикации виден в [GitHub Actions](https://github.com/KatrinaNov/quest-lostworld/actions).

Ключи на острове появляются у всей команды после первого нажатия «Начать приключение». После повторного входа по тому же коду прогресс острова восстанавливается из состояния команды.

Лабиринт использует каменный пол и изгороди. Для сохранения прогресса команды примените миграцию 004 в Supabase.

## Локальное демо без Supabase

Запустите `npm run dev` из папки проекта и откройте нужную ссылку в новой вкладке. Демо подходит для проверки карты и управления одним игроком.

| Локация | Локальный вход | Что проверить |
| --- | --- | --- |
| 1. Остров | [Демо острова](http://localhost:5173/?demo=1&loc=island) | Послание о кладе, появление ключей после «Начать приключение», каменная дверь и портал |
| 2. Затерянные джунгли | [Демо джунглей](http://localhost:5173/?demo=1&loc=minecraft) | Записка у костра, три символа, загадка о четырёх конвертах и вход в храм |
| 3. Храм испытаний | [Демо храма](http://localhost:5173/?demo=1&test=temple) | Прыжок на бегу, чекпоинт после последних огненных шаров, звёзды, плиты и переход в лабиринт |
| 4. Лабиринт забвения | [Демо лабиринта](http://localhost:5173/?demo=1&test=maze), [сразу у ворот с буквами](http://localhost:5173/?demo=1&test=maze&maze=final) | Маршрут, ловушки, сбор 14 букв, сборка фразы и поле кода. Код в локальном демо `0427` |
| 5. Замок дракона | [Демо замка](http://localhost:5173/?demo=1&test=castle) | Четыре печати, сундук и послание стража. В полной игре команда входит в замок после прохождения лабиринта |

На телефоне в той же Wi-Fi сети замените `localhost` в ссылке на сетевой адрес компьютера из вывода Vite. Для локальной проверки настоящей комнаты настройте `.env` и откройте локальный адрес без `demo=1`.

## Пауза во время поиска подсказок

Вернитесь в ту же вкладку после разблокировки. Игра обновит состояние комнаты. Если вкладка перезагрузилась и сохранила данные сеанса, кнопка «Продолжить» откроет последнюю комнату по сохранённому коду.

В Android Chrome полноэкранный режим восстанавливается при первом обычном касании после возврата. Кнопка «Во весь экран» остаётся доступна. На iPhone добавьте страницу на экран «Домой» через Safari, выберите «Открывать как веб‑приложение», если этот переключатель доступен, и запускайте игру с иконки.

## Конверты для Затерянных джунглей

Распечатайте [лист со знаками](docs/jungle-envelope-marks.png) на A4 и вырежьте четыре метки. Прикрепите по одной к каждому конверту и спрячьте их рядом с осветительными приборами. Подсказки внутри должны вместе приводить к слову «ХРАМ».

## Карта для Храма испытаний

Спрячьте бумажную карту лабиринта в библиотеке. После прохождения храма игроки увидят подсказку, где её искать.

## Код у ворот лабиринта

Новый финал появится после публикации сборки и применения [миграции 007](supabase/migrations/202611240007_maze_letters.sql). Команда собирает 14 букв. Каждый игрок расставляет их у себя, когда все дойдут до ворот. Затем игроки ищут реальную подсказку под подушкой. Верный ответ от любого участника открывает проход в замок для всей комнаты.

Когда код или слово будет выбрано, задайте его в SQL Editor Supabase. Поле принимает буквы и цифры, сохраняет ведущие нули и игнорирует регистр и пробелы по краям. До настройки поле открывается, а проход ждёт назначения кода.

```sql
insert into public.maze_gate_settings (singleton, entry_code)
values (true, 'ВЫБРАННЫЙ КОД')
on conflict (singleton) do update set entry_code = excluded.entry_code;
```

Для проверки в настоящей комнате по ссылке `?test=maze` подключите всех игроков до подбора первой буквы.

## Подготовка финала для организатора

Четыре печати одинаковы для любой команды. Замок появится онлайн после публикации фронтенда и применения миграции 006.

- Печать стихий. Подготовка реквизита не нужна. Ответ в игре — камень, вода, лист, огонь.
- Печать изумрудов. Спрячьте все шесть изумрудов. Команда вводит количество найденных камней.
- Печать алмазов. Оставьте шесть алмазов рядом с местом для решения. Ответ слева направо — 1, 4, 1.
- Печать следопыта. Отметьте одну из наклеек маленьким следом лапы. На обороте подложки напишите «КРЫЛО» и спрячьте её среди остальных наклеек, при желании рядом с бумажным лабиринтом.
- Спрячьте подарок у дивана в зале. Формулировка финальной подсказки хранится в [настройках замка](src/game/config/castleConfig.ts).
